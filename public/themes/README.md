The complete native palette includes shadows, focus and hovercard roles that
cannot be preserved by translating the theme's JSON preview. Claw's native
palette lives in src/styles/openclaw-reference/base.css instead.

`themes/miami.json` at the repository root supplies the catalog label and
light/dark preview swatches. The native stylesheet is authoritative for the
rendered palette; a user JSON theme with the same id still takes precedence.
